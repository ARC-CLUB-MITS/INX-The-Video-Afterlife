# Step 9 — Grounding & Hallucination Protection

INX now fails closed when retrieval is too weak. Gemini is never asked to guess when the transcript evidence does not confidently match the question.

## Safety gates
- Retrieval confidence threshold (`QA_MIN_RETRIEVAL_SCORE`, default `0.58`).
- Meaningful-question token check.
- Keyword anchor check among the strongest retrieved chunks, while allowing strong semantic matches.
- Gemini must return `supported=true` plus valid database chunk indices for an answer to be accepted.
- Citation indices are validated against the exact retrieved chunks.
- At least one citation must belong to the top three retrieved chunks.
- Unsupported Gemini responses are converted to the fixed refusal message.
- Answer length is capped (`QA_MAX_ANSWER_CHARS`, default 1200).
- Timestamps and source text are always taken from MySQL retrieval results, never generated by Gemini.

## Core rule

> Retrieve first → gate confidence → answer second → verify citations → otherwise refuse.

This is intentionally conservative: a refusal is preferable to a plausible but unsupported answer.
